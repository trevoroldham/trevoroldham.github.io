Quantum Option Pricing

Quantum Amplitude Estimation (QAE) redefines the evaluation of financial instruments by offering a provable quadratic speedup over classical Monte Carlo methods. By mapping probability distributions directly into quantum states and applying amplitude amplification, this pipeline rapidly accelerates the convergence of complex pricing models. This structural advantage enables the precise calculation of expected option payoffs in highly volatile markets, streamlining quantitative risk analysis while significantly reducing computational overhead.

Portfolio Rebalancer

A production-grade classical web application designed to bridge the gap between quantum-inspired optimization and real-world portfolio management. This tool takes the exact QUBO mapping and mathematical constraints from a quantum portfolio project and executes them locally using Qiskit's NumPyMinimumEigensolver. By moving away from noisy QPU hardware to an exact classical eigensolver, it isolates the mathematical behavior of discrete asset allocation while maintaining the rigorous constraint mapping required for quantum execution.

Molecular VQE

A scalable, modular command-line tool and web application for simulating molecular ground states using the Variational Quantum Eigensolver (VQE). Quantum computing transcends classical binary limitations by leveraging superposition to navigate high-dimensional optimization problems. Built on IBM's Qiskit ecosystem, this project maps fermionic operators to a qubit Hamiltonian, utilizing hardware-efficient ansätze and active space approximations. It allows researchers to seamlessly route circuits from local statevector simulation to cloud-native physical IBM Quantum processors.

CNDO/2 Implementation

A comprehensive C++ implementation of the CNDO/2 computational quantum chemistry model, featuring Direct Inversion in the Iterative Subspace (DIIS) and Broyden–Fletcher–Goldfarb–Shanno (BFGS) optimization. Developed for UC Berkeley's CHEM 279, this project calculates analytical gradients and performs self-consistent field (SCF) minimization on closed or open-shell molecules. It provides a robust, low-level framework for evaluating molecular integrals and optimizing bond lengths using advanced numerical algorithms.
